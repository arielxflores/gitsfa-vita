# Description
An unofficial PS Vita version of Ghost in the Shell: Stand Alone Complex - First Assault Online, the PC shooter whose servers closed in 2017. It is a new engine written for the Vita (VitaSDK, vitaGL) that plays the game's content offline: the 13 battlefields and the training rooms, Team Deathmatch, Demolition, Terminal Conquest, Elimination and Ghost Assault with bots, the 12 operatives with their skills, and the armory's 50 weapons. Touch works in the menus.

Multiplayer rooms for up to 8 players work over ad-hoc, the same Wi-Fi, or the internet without a server: the host's waiting room shows a room code and the other players type it in. This is a public test: multiplayer has only been tried with one Vita and a computer playing the second player, so reports are welcome.

The game's data is not distributed. A data builder for Windows (in the release) makes it from the user's own install of the PC game. No code of the original game is used.
